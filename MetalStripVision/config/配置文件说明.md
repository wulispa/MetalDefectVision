# 配置文件说明

## 概述

所有配置文件都集中在 `config/` 文件夹中，便于管理和维护。

## 目录结构

```
MetalStripVision/
├── config/                        # 配置文件夹
│   ├── config.xml                 # 主配置文件
│   │   ├── 相机配置
│   │   ├── 图片保存配置
│   │   └── 用户配置（登录账户）
│   │
│   └── defect_colors.xml          # 缺陷颜色配置
│       └── 按classId配置缺陷显示颜色
│
├── Model/                         # 模型文件夹
│   ├── Tag/                       # 类别标签
│   │   ├── Up_metal.txt           # 上表面类别
│   │   └── Down_metal.txt         # 下表面类别
│   │
│   └── Trt/                       # TensorRT模型
│       ├── Up_metal.trt           # 上表面模型
│       └── Down_metal.trt         # 下表面模型
│
├── MetalStripVision.exe           # 主程序
└── log_YYYY_MM_DD.txt             # 运行日志
```

## 配置文件详解

### 1. config.xml - 主配置文件

**位置：** `config/config.xml`

**用途：**
- 相机配置（序列号、算法类型、触发模式等）
- 图片保存配置（保存路径、日期文件夹等）
- 用户配置（管理员和操作员账户）

**示例：**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<Configuration>
    <Cameras>
        <Camera id="1" serialNumber="CAMERA1_SN" type="Traditional" triggerMode="1" enabled="true"/>
        <Camera id="2" serialNumber="CAMERA2_SN" type="AI" triggerMode="1" enabled="true"/>
        <Camera id="3" serialNumber="CAMERA3_SN" type="AI" triggerMode="1" enabled="false"/>
    </Cameras>

    <ImageSave>
        <Path>images</Path>
        <EnableDateFolder>true</EnableDateFolder>
    </ImageSave>

    <Users>
        <User username="admin" role="admin">
            <PasswordHash>240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9</PasswordHash>
        </User>
        <User username="operator" role="operator">
            <PasswordHash>a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3</PasswordHash>
        </User>
    </Users>
</Configuration>
```

**相关文档：**
- 修改密码：通过程序界面修改
- 用户管理：见 `用户登录系统.md`

### 2. defect_colors.xml - 缺陷颜色配置

**位置：** `config/defect_colors.xml`

**用途：** 配置不同缺陷类型的显示颜色

**示例：**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<DefectColors>
    <Color classId="0" r="255" g="0" b="0" name="红色"/>
    <Color classId="1" r="0" g="255" b="0" name="绿色"/>
    <Color classId="2" r="0" g="0" b="255" name="蓝色"/>
    <!-- 可添加更多颜色... -->
</DefectColors>
```

**使用方法：**
1. 查看 `Model/Tag/Up_metal.txt` 确认缺陷类型和行号
2. 行号-1 = classId
3. 在此文件中配置对应的颜色

**相关文档：** 详见 `缺陷颜色配置说明.md`

## Model文件夹说明

### Tag文件夹 - 类别标签

**位置：** `Model/Tag/`

**格式：** 每行一个类别名称
```
qipao
yijiao
```

**说明：**
- 第一行对应 classId=0
- 第二行对应 classId=1
- 依此类推

### Trt文件夹 - TensorRT模型

**位置：** `Model/Trt/`

**文件格式：** `.trt` (TensorRT引擎文件)

**命名规则：** 与Tag文件对应
- `Up_metal.txt` → `Up_metal.trt`
- `Down_metal.txt` → `Down_metal.trt`

## 配置文件修改

### 修改相机配置

1. 打开 `config/config.xml`
2. 找到 `<Cameras>` 部分
3. 修改对应相机的参数
4. 重启程序生效

**可修改的参数：**
- `serialNumber`: 相机序列号
- `type`: 算法类型（Traditional/AI）
- `triggerMode`: 触发模式（0=硬件触发，1=软件触发）
- `enabled`: 是否启用

### 修改缺陷颜色

1. 打开 `config/defect_colors.xml`
2. 修改对应classId的RGB值
3. 重启程序生效

详细说明见 `缺陷颜色配置说明.md`

### 添加新的缺陷类型

1. 在 `Model/Tag/Up_metal.txt` 中添加新类别名称
2. 在 `config/defect_colors.xml` 中添加对应颜色
3. 重新训练模型并放在 `Model/Trt/` 中
4. 重启程序

### 修改用户密码

**方法1：通过程序界面**
1. 启动程序并登录
2. 点击"修改密码"按钮
3. 管理员可以为任何用户修改密码

**方法2：手动修改config.xml**
1. 打开 `config/config.xml`
2. 找到对应用户的 `<PasswordHash>` 标签
3. 使用SHA256哈希工具生成新密码的哈希值
4. 替换哈希值并保存
5. 重启程序

## 日志文件

**内容：**
- 程序启动/关闭信息

- 错误和警告信息

**用途：**
- 调试问题
- 查看程序运行状态
- 分析检测数据

## 常见问题

### Q: 配置文件修改后不生效？
**A:** 确保已重启程序。大多数配置在启动时加载，运行时修改不会立即生效。

### Q: 找不到config文件夹？
**A:** 首次运行程序会自动创建。如果缺失，可手动创建 `config/` 文件夹并放入配置文件。

### Q: Model文件夹在哪里？
**A:** `Model/` 文件夹应放在程序可执行文件同目录下，包含 `Tag/` 和 `Trt/` 子文件夹。

### Q: 如何备份配置？
**A:** 复制整个 `config/` 文件夹即可。建议定期备份。

### Q: 配置文件损坏怎么办？
**A:** 删除损坏的文件，程序会使用默认配置重新创建。但对于用户配置，需要重新设置账户。

## 配置文件模板

如果需要恢复默认配置，可以删除 `config/` 文件夹中的文件，程序会自动创建：

1. **config.xml** - 包含默认的相机配置和示例用户
2. **defect_colors.xml** - 包含默认的7种颜色

默认用户：
- 管理员：`admin` / `admin`
- 操作员：`operator` / `123`

## 安全建议

1. **密码安全**：定期修改默认密码
2. **权限控制**：使用操作员账户进行日常检测，管理员账户用于配置
3. **配置备份**：定期备份config文件夹
4. **日志审查**：定期检查日志文件，发现异常及时处理
5. **文件权限**：确保config文件夹不被普通用户随意修改

## 配置文件版本控制

建议使用Git或其他版本控制工具管理配置文件：

```
config/
├── .gitignore           # 忽略敏感信息
├── config.xml.template  # 配置模板（不含敏感信息）
├── defect_colors.xml    # 颜色配置（可提交）
└── README.md            # 配置说明
```

`.gitignore` 内容：
```
# 忽略包含敏感信息的配置文件
config.xml

# 但保留模板
!config.xml.template
```
