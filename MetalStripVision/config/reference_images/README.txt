==================================================
相机参考图片使用说明
==================================================

【功能说明】
此目录用于存放每个相机的参考图片，用于ROI绘制。
参考图片用于在参数设置中显示和绘制ROI框。

【命名规则】
文件名格式：camera{相机ID}.jpg

示例：
  - camera1.jpg  (相机1的参考图片)
  - camera2.jpg  (相机2的参考图片)
  - camera3.jpg  (相机3的参考图片)

【如何添加参考图片】
方法1：通过参数设置界面
  1. 打开参数设置界面
  2. 选择对应的相机
  3. 点击"从实时相机更新"按钮
  4. 系统会自动保存当前画面为参考图片

方法2：手动添加
  1. 准备好对应的图片文件（.jpg格式）
  2. 将文件重命名为：camera1.jpg, camera2.jpg, camera3.jpg
  3. 复制到此目录（config/reference_images/）

【图片要求】
  - 格式：JPG（.jpg）
  - 建议分辨率：与相机实际分辨率一致
  - 文件大小：建议不超过5MB

【注意事项】
  1. 每个相机只能有1张参考图片
  2. 新图片会覆盖旧图片
  3. 参考图片与用户集无关，是相机级别的配置
  4. 参考图片损坏或丢失不影响程序运行

【常见问题】
Q: 为什么看不到参考图片？
A: 请检查文件名是否正确（camera1.jpg等）
   确保图片格式为JPG，且文件在此目录下

Q: ROI参数保存在哪里？
A: ROI参数保存在用户集配置中，与参考图片分离
   每个相机可以有多个用户集，每个用户集有独立的ROI参数

Q: 如何切换使用参考图片或实时相机？
A: 在参数设置界面中，选择"历史图片"或"实时相机采图"
